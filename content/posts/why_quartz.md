If you've read my index page, and if I haven't added any theming or made custom CSS for this website, you may have noticed that this webpage was built using  [Quartz](https://quartz.jzhao.xyz/).

This begs the question, why Quartz? There are so many different ways you can build a website that probably allow me, the developer and owner of this website, to flex my skills and show off my technical prowess. I could be using Tailwind/Bootstrap/whatever CSS framework and React/Angular/whatever web framework my heart desires.

And originally, that's what I tried doing! My first portfolio website I tried making was some React site I tried building using Tailwind. 

![An image from during the development of my first site](why_quartz_1.png)
*An image from during the development of my very first site*

Eventually, I ran into a few problems:
- I spent more time trying to make a cool WebGL shader, than actually putting any content on the site
- I spent more time learning how to use React, than actually putting any content on the site
- I didn't put any content on the site, because I don't like doing front-end web development

I spent way too much time trying to make things look cool, and I ended up getting to a point where I just didn't want to work on it anymore, so the site just stood there in a state of disrepair and nothingness: a true testament to my disdain for front-end web development.

I did learn a lot from the experience, thankfully, and I ended up being somewhat proud of how the site looked, even if it had no content, the *"About Me"* page still had placeholder text, and each project card just was just a link to the GitHub repo instead of a write-up about the project.

That being said, I actually want content to be posted on my site, regardless of how it's done, or how it looks. Since I already use Obsidian for a bunch of other things, I figured there must've been a way to publish either those notes, or things in markdown in general, which is what led me to using Quartz. 

Now since I have no barrier to letting me write things and post them without having to create HTML templates for each kind of page I want to show; hopefully, it'll force me to actually post and write more instead of thinking about how awesome my website is going to look if I just develop this one more React component.

That being said, I do want this to be *my* site, so hopefully I can eventually get around to customizing how the site actually looks, but that's an endeavor for future me, and future me will get around to it *eventually*, and future me will strike this text out and have some funny line below talking about how I did get around to it ***eventually***.
